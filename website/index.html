Architecture & Verification

How it works

A 5-step pipeline designed around zero interference, zero hallucination, and full citation attribution.

01

Detect

Silently identifies "I agree" checkboxes, checkout buttons, and policy pages without delaying clicks or altering form behavior.

02

Fetch

Extracts and cleans raw policy text in the background, isolating substantive legal terms from layout boilerplate.

03

Analyze

Evaluates auto-renewals, non-refundable clauses, cancellation barriers, and hidden fees using LLM comprehension with strict rule scoring.

04

Verify Quote

The backend searches the raw policy text for every quote returned by the model. If not found, the quote is flagged as unverified.

05

Show Card

Renders a compact, isolated risk card with overall risk score, sorted flags, and verified quotations before you click Agree.

Quick Setup

Install the extension

PolicyDecode runs as a lightweight Manifest V3 Chrome extension. Install it in less than a minute via Chrome's Developer mode.

1

Download from GitHub

Clone or download the repository ZIP file from GitHub to your local machine.

2

Open chrome://extensions

Open Google Chrome (or Edge / Brave) and navigate to the Extensions management page.

3

Turn on Developer mode

Toggle the Developer mode switch located in the upper-right corner of the Extensions page.

4

Load unpacked

Click the Load unpacked button and select the extension folder inside the PolicyDecode directory.

Chrome Extensions URL

Copy and paste into your browser address bar:

chrome://extensions

Backend Server

Ensure the local backend is running:

cd backend && npm start
Transparency

Limits and future scope

We believe in complete transparency about what PolicyDecode does today and where we are taking it next.

Current Limitations

  • • Desktop Chrome only today: Runs as a Manifest V3 extension on desktop Chromium browsers (Google Chrome, Brave, Microsoft Edge).
  • • Results can be wrong or incomplete: Automated language models can misinterpret nuance or overlook unconventional legal provisions.
  • • Strictly not legal advice: PolicyDecode provides automated heuristics for consumer awareness. It does not constitute legal counsel or a formal contract evaluation.
Always inspect binding legal contracts and cancellation procedures directly when significant rights or financial sums are involved.

Future Scope

  • → Mobile browser support: Bringing automatic agreement analysis to mobile browsers (Safari Web Extensions for iOS and Firefox for Android).
  • → Dark pattern detector: Flagging manipulative UI patterns on checkout pages, including disguised subscription renewals, pre-selected checkboxes, and artificial urgency timers.
  • → Custom risk sensitivities: User-customizable alerts tailored to specific personal deal-breakers (e.g. arbitration clauses, data-selling clauses, or strict return windows).
